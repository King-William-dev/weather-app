# Weather Dashboard App

A modern, responsive Weather Dashboard web application built using HTML, CSS, and JavaScript with live weather data integration from the OpenWeather API.

---

## 🌟 Project Overview

This project is a fully functional weather application that allows users to:

- Search weather by city name
- View current weather conditions
- Access 5-day / forecast data
- Use GPS location for local weather
- Toggle dark mode
- View animated loading states
- Save search history using localStorage
- Experience a responsive mobile-friendly UI

The application was designed with a clean dashboard-style interface and optimized for both desktop and mobile devices.

---

## 🚀 Features

### 🌤 Current Weather Data

Displays:

- Temperature
- Weather condition
- Humidity
- Wind speed
- Weather icons

### 📊 Forecast System

- Multi-time weather forecast cards
- Forecast temperature display
- Dynamic weather descriptions

### 📍 Geolocation Support

Users can fetch weather data automatically using browser GPS location services.

### 🌙 Dark Mode

Modern dark/light theme switching for improved user experience.

### ⚡ Animated UI

- Loading spinner
- Smooth card animations
- Hover effects
- Responsive transitions

### 🧠 Search History

Uses browser localStorage to save and display recently searched cities.

## 🔗 API Integration

Weather data is fetched dynamically using the OpenWeather API.

### API Endpoints Used

#### Current Weather

```bash
https://api.openweathermap.org/data/2.5/weather
```

#### Forecast Weather

```bash
https://api.openweathermap.org/data/2.5/forecast
```
